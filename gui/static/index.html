Behaviour

Matching & files

Filters

A non-empty whitelist wins: only listed entries pass and the matching blacklist is ignored. Plex library types are movie/show; Jellyfin and Emby use movies/tvshows.

User mappings

Only needed when the same person has a different username on different servers, or one account fans out to several users.

Library mappings

Only needed when a library has a different name on different servers.

User sync rules

Push these users from one server to another, overriding the user filters for that direction. Use * for all users.

Library sync rules

Push these libraries from one server to another, overriding the library name and type filters for that direction. Use * for all libraries.

Plex watchlist → Jellyfin / Emby favorites

Anything on a person's Plex watchlist that's in your Jellyfin or Emby library is added to their favorites there (the ♥ row on the home screen). Titles you don't have yet are listed as not in library.

Linked Plex accounts

Each person signs in with their own Plex account, because a watchlist belongs to the account, not your server. Plex Home managed users have no login of their own, so they can't be linked.
